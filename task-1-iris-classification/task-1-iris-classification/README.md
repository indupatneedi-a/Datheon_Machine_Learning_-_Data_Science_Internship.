# Task 1: Multi-Class Benchmark Classification Pipeline (Iris)

Classification of iris species using Scikit-Learn.

## What this notebook does
- Loads the Iris dataset with Pandas
- Exploratory pairplots with Seaborn
- 80/20 stratified train/test split
- Feature scaling with StandardScaler (fitted on training data only)
- Trains Logistic Regression and Decision Tree classifiers
- Benchmarks accuracy, precision, recall and F1-score
- Confusion matrix heatmaps and decision boundary plots

## Results
- Logistic Regression accuracy: 93.33%
- Decision Tree accuracy: 96.67%
